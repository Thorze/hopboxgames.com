# hopboxgames.com

Page d'accueil de Hop Box, servie par GitHub Pages (fichier `CNAME`).

- Test fermé : la page explique comment devenir testeur (groupe Google, test Google Play, installation).
- Sortie publique : dans `index.html`, mettre `const PUBLIC = true;` — il ne reste que le bouton Google Play.
- Lien d'invitation : `https://hopboxgames.com/?ami=CODE` affiche le code ami à ajouter dans le jeu.
- `confidentialite.html` : règles de confidentialité (adresse à donner dans la Play Console).
